# Pre-work: preparando o ambiente do curso

Este repositório é um **pre-work** (não é uma aula). O objetivo é você validar, antes do
curso começar, que consegue usar o seu ambiente do GitHub Enterprise da mesma forma que
usará durante as aulas: criar um repositório a partir de um template, abrir um Codespace,
e rodar uma aplicação.

## ✅ Pré-requisitos de acesso

Antes de começar, confirme com o professor/organização:

- Sua conta está **autorizada via SSO/SAML** na organização do GitHub Enterprise usada no curso.
- Você é **membro** da organização correta.
- A funcionalidade de **Codespaces está habilitada** para você/organização.

## 🚀 Como iniciar o pre-work

1. Clique no botão abaixo para criar sua própria cópia deste repositório.
2. Aguarde alguns segundos: um bot vai criar automaticamente a **primeira issue** no seu
   repositório com as instruções para abrir o Codespace.
3. Siga as instruções da issue até ver a página de sucesso da aplicação.
4. Comente `concluído` na issue para receber as instruções de limpeza do ambiente.

> ainda vai parecer com este aqui (a mesma página que você está vendo agora)!** Isso é
